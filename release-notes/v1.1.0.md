# PhyloParallelograms 1.1.0

## New features

- The .phypar format was based on SQLite and has been changed to a text-based format (for portability reasons)
- Old SQLite-based files can still be read but all new files are stored in the new text-based format
- Added a note feature that should be used to record the paper associated with a given dataset

- Set min confidence and min concordance now undoable/redoable
