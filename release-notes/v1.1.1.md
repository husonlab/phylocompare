# PhyloParallelograms 1.1.1

## New features

- Using new version of PhyloFusion available in SplitsTree:
- It has a new option, Reticulate Placement -
  During calculation of a network containing a set of input trees, there are now three new ways to
  break times: smallest, largest and normal. The former two chose the subnetwork with the smallest or
  largest number of taxa to be below a reticulate node, respectively, whereas the latter option
  tries to ensure that all reticulate edges are normal, that is, not short cut edges between ancestors
  and path descendents.
- PhyloFusion now uses non-negative least-squares to set network edge lengths, by default, and other
  methods are available.
- There is a new panel for specifically setting options for the PhyloFusion algorithm (for advanced users)
